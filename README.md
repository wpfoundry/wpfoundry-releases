# WP Foundry

WP Foundry is a desktop application for managing WordPress websites on Windows, macOS, and Linux.

Site data stays on your computer. The app talks to each site over HTTPS through the WP Foundry Helper plugin. There is no WP Foundry cloud.

**Website:** https://wpfoundry.app  
**Download:** https://wpfoundry.app/download/  
**Docs:** https://wpfoundry.app/how-to-use-wp-foundry/  
**What it is:** https://wpfoundry.app/what-is-wp-foundry/  
**Created by:** [Mike Beck](https://wpfoundry.app/about-me/) (first public release: 2024)
